# Data

The raw Excel file is intentionally not committed because it is a large source file and is available publicly from the UCI Machine Learning Repository.

Download the official dataset here:

- https://archive.ics.uci.edu/dataset/352/online+retail
- Direct download: https://archive.ics.uci.edu/static/public/352/online+retail.zip

After downloading and extracting, place the file at:

```text
data/Online Retail.xlsx
```

The analysis script expects that filename.
